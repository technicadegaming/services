# Technicade Labs — traffic and monetization rollout

## Shipped experiences
- Don't Push the Button (labs.html): free interactive toy, local progress.
- Would You Rather (would-you-rather.html): 20 questions; no vote collection.
- Fake Achievement Generator (fake-achievement.html): local PNG rendering and shareable image.
- Random Challenge Wheel (challenge-wheel.html): custom prompts, local random selection.

## Analytics: recommended next step
1. Verify GitHub Pages deployment of each path from a desktop and mobile browser.
2. Use privacy-conscious pageview analytics (e.g., Cloudflare Web Analytics) only after verifying account/configuration, updated privacy notice, and any consent requirements.
3. Track pageviews, returning visitors, referrals, and play events where appropriate. Do not log challenge text, achievement names, or generated contents.
4. Record weekly traffic and share conversion before making ad placement decisions.

## Monetization gate
- Start with free games and organic sharing.
- Seek meaningful repeat traffic before requesting an ad-network review; eligibility and revenue are not guaranteed.
- Avoid misleading ad placement or incentives to click.
- Consider optional, clearly described one-time paid features *only* after testing demand.
- Keep research-stage adult creator software separate until processor policies and legal requirements are reviewed.

## Quality checks before promotion
- Play each game on small mobile and desktop screens.
- Test image downloads in Chrome, Edge, and mobile browsers.
- Check keyboard accessibility, copy/share fallback, and reset behavior.
- Ensure site-wide privacy and terms accurately cover any analytics/ads before enabling them.

No analytics script, ad code, or payment integration has been installed by this change.
