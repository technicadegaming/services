Arcade Prize Machine Takes Credits but Doesn't Dispense: A Troubleshooting Checklist

A safe, practical process to diagnose prize-dispense failures without buying random replacement parts.

Technicade independent technical resources · Check your equipment manual

Share on Facebook

Quick answer

If credits deduct but no prize drops, first distinguish between a failure to authorize a vend, an actuator that never moves, a moving mechanism that misses the prize, and a machine that does deliver but never registers the delivery. These are different faults; the same visible complaint can have several causes.

Record one controlled test

With the machine in its approved service mode, record the game model and revision, active error codes, credit and vend counters, whether the vend command is issued, whether the motor or solenoid moves, and whether the prize sensor changes state. Take a short video that includes the screen and mechanism. Avoid repeated paid test plays.

Check obvious physical problems with power isolated

Follow the manufacturer's shutdown procedure first. Look for jammed merchandise, worn belts, loose linkages, bent delivery flaps, obstructed prize paths, disconnected plugs, and debris around optical sensors. Do not reach into energized mechanisms or bypass door switches.

Use the machine's documented diagnostics

Where the manual provides I/O tests, check command outputs and sensor inputs independently. A motor moving in a test does not prove that its delivery sensor is aligned; likewise, an LED on a sensor is not by itself proof that the controller sees the signal. Record the test results rather than replacing parts by guesswork.

Rule out simple configuration and communication issues

Confirm that the selection is enabled, merchandise is correctly loaded, any dispenser inventory counter is correct, and the game/card system is configured to grant the intended credit or play. If a card reader deducted value without sending a successful start signal, compare the reader's and controller's event logs before changing prices.

When to stop and escalate

If wiring is damaged, mains power is exposed, a fuse repeatedly blows, or the dispenser jams under load, stop service and contact a qualified technician. Provide the manufacturer with the exact model, controller revision, symptoms, test video, and error codes. Return to guest play only after multiple successful supervised test vends.
